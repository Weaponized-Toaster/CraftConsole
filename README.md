## How to use CraftConsole
To use CraftConsole, it is very simple. Just insert a **Floppy Disk** into the **Disk Drive** and start the game!

### How to set up CraftConsole
It is surprisingly simple, to install CraftConsole, all you need to do is run these two commands on a computer
```
wget <link_here> install

install.lua
```

You also need:
- A disk drive to the left of the computer
- A 3x3 Advanced Monitor infront of the computer
